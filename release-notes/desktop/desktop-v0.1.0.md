Install the Windows uploader and choose the folder containing AzerothSurvivors.exe to get started.

- Automatically installs the recorder addon and finds your recordings.
- Downloads app and addon updates for you. Addon updates install after you close the game; app updates apply when you next safely start the uploader.
- Keeps your saved recordings when updating.

Windows or your browser may show an unknown-publisher warning because this installer is unsigned.

At the time of this release, website sign-in and uploads were not yet available.
